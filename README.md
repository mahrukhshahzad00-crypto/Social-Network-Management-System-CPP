
# Social Network Management System

A console-based social networking application developed in **C++**, demonstrating the practical implementation of **Data Structures and Algorithms (DSA)**, Object-Oriented Programming, and linked lists.

## Project Overview

This project simulates a basic social networking platform where users can create accounts, manage friendships, find mutual connections, and receive friend recommendations.

User accounts and relationships are managed using custom linked-list data structures.

## Key Features

- Create and delete user accounts
- Search for existing users
- Add and remove friends
- Display friends of a specific user
- Find mutual friends between users
- Recommend friends based on connections
- Display a friendship graph using an adjacency matrix

## Technologies Used

- **Language:** C++
- **Concepts:** Data Structures and Algorithms
- **Data Structures:** Singly Linked Lists, Graph Representation
- **Programming Paradigm:** Object-Oriented Programming (OOP)
- **Development Environment:** VS Code

## How to Run

### Requirements
- Windows operating system
- C++ compiler (Microsoft Visual C++)

### Steps

1. Clone or download this repository.
2. Open the project folder in your development environment.
3. Open a Visual Studio Developer Command Prompt.
4. Compile the code:

    cl /EHsc /std:c++17 main.cpp /Fe:SocialNetwork.exe

5. Run the program:

    SocialNetwork.exe
